▸ Prerequisites
⚙️ What You Need
1

Clone MicroChat-CPU

If you haven't already, clone the repo:

git clone https://github.com/Matrix-Research-Ai/MicroChat-CPU.git
cd MicroChat-CPU
2

Install dependencies

# Using uv (recommended)
uv sync --extra cpu
source .venv/bin/activate

# Or using pip
pip install torch numpy pyarrow tiktoken
3

Prepare the dataset

Convert your JSONL to Parquet (pretraining) or Chat JSONL (SFT). Run this in your epub2dataset directory:

python3 -c "
import json, pyarrow as pa, pyarrow.parquet as pq, os
lines = [json.loads(l) for l in open('dataset.jsonl')]
texts = [l['response'] for l in lines]
out = os.path.expanduser('~/epub2dataset_data')
os.makedirs(out, exist_ok=True)
pq.write_table(pa.table({'text': pa.array(texts)}), f'{out}/shard_00000.parquet')
val = texts[-len(texts)//20:]
pq.write_table(pa.table({'text': pa.array(val)}), f'{out}/shard_00001.parquet')
# Also create SFT format
with open(f'{out}/sft.jsonl', 'w') as f:
for l in lines:
chat = [{'role':'user','content':l['instruction']+'\\n'+l['input']},
{'role':'assistant','content':l['response']}]
f.write(json.dumps(chat, ensure_ascii=False)+'\\n')
print('Done:', out)
"
▸ Training Options

Train a GPT model from scratch on the raw encyclopedia text (next-token prediction).

1

Copy data to MicroChat-CPU's data directory

# Find the base_data directory
python3 -c "from nanochat.common import get_base_dir; print(get_base_dir())"

# Copy your dataset there
cp ~/epub2dataset_data/shard_00000.parquet /path/to/base_data_climbmix/
cp ~/epub2dataset_data/shard_00001.parquet /path/to/base_data_climbmix/
⚠️ Important
The dataloader reads all parquet files except the last one as training, and the last one as validation. Make sure the files are in the right order (training first, validation last).
2

Run training

# Single-node CPU training (GPT-2 scale, depth=4)
bash runs/runcpu_distributed.sh single --depth=4 --num-iterations=200 --max-seq-len=512 --device-batch-size=1 --total-batch-size=512

# Or run directly
python -m scripts.cpu_train --depth=4 --num-iterations=200 --max-seq-len=512 --device-batch-size=1 --total-batch-size=512 --eval-tokens=0 --core-metric-every=-1
3

Chat with the trained model

python -m scripts.chat_cli --model-tag=d4
💡 Tip: With 2,435 examples at ~400 tokens each, that's ~1M total tokens. A depth=4 model (40M params) will overfit quickly — use this as a test/smoke run. For actual learning, consider combining with the full ClimbMix dataset.

Fine-tune an existing pretrained checkpoint on the encyclopedia in chat format.

1

Edit chat_sft.py to add your dataset

Open scripts/chat_sft.py and add CustomJSON to the training mixture:

# At the top of the file (already imported)
from tasks.customjson import CustomJSON

# Inside train_tasks list (around line 165), add as FIRST task:
train_tasks = [
CustomJSON(filepath=r"C:\Users\Admin\epub2dataset_data\encyclopedia_sft.jsonl"),
SmolTalk(split="train"),
...
]
⚠️ Windows path note
On Windows, use a raw string r"C:\path\to\file.jsonl" or forward slashes "C:/Users/.../file.jsonl". Backslashes without the r prefix will be treated as escape sequences.
2

Run SFT

# SFT with CPU (needs a pretrained checkpoint)
python -m scripts.chat_sft --device-type=cpu --num-iterations=100

# With specific model checkpoint
python -m scripts.chat_sft --device-type=cpu --model-tag=d12 --model-step=1000 --num-iterations=50
3

Chat with the fine-tuned model

python -m scripts.chat_cli --model-tag=chatsft/d12
💡 Note: SFT requires a pretrained checkpoint as a starting point. If you haven't run pretraining yet, first train a base model or download one. Run python -m scripts.base_train --depth=4 --num-iterations=50 to create one.
▸ Common CLI Flags
FlagDefaultDescription
--depth4Number of transformer layers (4≈40M, 8≈120M, 12≈300M params)
--num-iterations50Training steps (-1 = full epoch)
--max-seq-len2048Context window size
--device-batch-size1Samples per device per step (CPU needs 1–2)
--total-batch-size524288Total tokens per step (lower for CPU)
--syntheticfalseUse fake data for testing (no dataset needed)
--dry-runfalseValidate setup without actual training
--profilefalseRun profiler to see where time is spent
--device-typeautocpu, cuda, or mps
▸ Quick Smoke Test

Run this to verify MicroChat-CPU works on your machine before using your real dataset:

cd ~/Downloads/MicroChat-CPU
source .venv/bin/activate
python -m scripts.cpu_train --synthetic --dry-run --depth=2

This downloads nothing and runs in 2 seconds. If it passes, everything is installed correctly.
