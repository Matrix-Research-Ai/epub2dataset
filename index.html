📚
epub2dataset

Convert EPUB ebooks into production-ready LLM training datasets. 10-dim quality scoring. 3 output styles. 4 formats.

GitHub v5.0.0 58 tests Python 3.10+ MIT License

▸ Quick Install

# Install
pip install ebooklib beautifulsoup4

# Convert all EPUBs in a folder
epub2dataset ./ebooks -o dataset.jsonl

# Chat-style for conversational models
epub2dataset ./ebooks -o chat.jsonl --style chat

# Parquet for faster CPU I/O
epub2dataset ./ebooks -o dataset.parquet

# Preview before building
epub2dataset ./ebooks --stats

▸ Features

✓
10-dim Quality Scoring
Code2Doc-inspired rubric (completeness, clarity, coherence, density, structure, length, formatting, uniqueness, readability, naturalness)
✓
3 Output Styles
Instruction (Alpaca ### markers), Completion, Chat (messages array)
✓
4 Output Formats
JSONL, JSON, Apache Parquet, Apache Arrow (zero-copy)
✓
MinHash LSH Dedup
Global near-duplicate detection across all sources
✓
PII Detection
Email, phone, SSN, IP, credit card — optional redaction
✓
Eval Decontamination
Built-in benchmark phrase matching + SHA256 fingerprinting
✓
Domain Classification
Narrative, technical, code, dialogue, reference
✓
Structured Packing
SPLICE-inspired BOS/EOS packing for context utilization
✓
AI-Generated Text Detection
Burstiness, transition diversity, sentence starter analysis
✓
3 Pre-set Recipes
Strict (≥7.5), Balanced (≥6.0), Lenient (≥4.0)

▸ Recipes

Strict

min=500ch, max=4K, quality≥7.5, high dedup. For production fine-tuning.

epub2dataset ./ebooks --recipe strict

Balanced

min=300ch, max=8K, quality≥6.0. General purpose (default).

epub2dataset ./ebooks

Lenient

min=150ch, max=16K, quality≥4.0. Maximum data retention.

epub2dataset ./ebooks --recipe lenient
